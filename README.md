# donnyautomation.com

The public company page for **DONNY NGUYEN LLC**, served by GitHub Pages at the apex of
`donnyautomation.com`.

Every claim on this page is checkable from a public source that is linked next to it. There
are no customer counts, no revenue figures and no testimonials, because none of those could
be verified at the time of writing. Numbers that would go stale on a static page (npm
download counts, settlement totals) are deliberately left off and linked to their live
source instead.

- `index.html` — the page. Single file, no external requests, no trackers, no cookies.
- `CNAME` — the custom domain GitHub Pages serves this from.
