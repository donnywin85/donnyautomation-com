Shopify store search not finding SKUs, barcodes or part numbers: why, and how to fix it

A shopper types a part number they know is in your catalog and gets no results, or the wrong ones. This page explains what the built-in storefront search matches for SKUs and barcodes, what to check first, and the fixes you can make without installing anything.

Facts about the built-in search come from the Shopify Help Center page Search behavior, read on November 22, 2026. Shopify can change that page; check it if something here no longer matches.

What the built-in search matches

According to the Help Center page (read November 22, 2026):

  • Products are searched by title, description, product type, tags, variant title, vendor, variant SKU and variant barcode.
  • A shopper can find a product by typing its full SKU or barcode.
  • A partial code matches from the first character: the first 3 to 15 characters of a SKU, or the first 3 to 10 characters of a barcode, with or without hyphens. Shorter or longer partial codes don't match; for a longer piece, the shopper needs the full code.
  • Characters from the middle or end of a code don't match, unless they form a complete segment separated by hyphens, slashes or spaces.
  • A short partial code can also return other products whose codes start with the same characters.
  • Typo tolerance tries to fix words that differ from the search term by one letter. A search limited to one field (see below) looks for an exact match, so a misspelling there won't be corrected.
  • The search results page (after pressing Enter) and predictive search (suggestions while typing) are separate search types.

The Help Center page does not mention metafields, letter case, or spaces typed inside a code. If your part numbers live in a metafield and nowhere else, or shoppers type codes with spaces in different places, test those cases on your own store rather than assuming either way.

Common reasons a code search comes back empty

  1. The shopper typed the middle or end of the code. For example, the last digits printed on a part, or a barcode without its leading digits.
  2. The partial code is too long or too short. Fewer than 3 characters, more than 15 for a SKU, or more than 10 for a barcode, without typing the full code.
  3. The code isn't in the SKU or Barcode field. The partial-code rules above are described for the variant SKU and Barcode fields. A code kept in the description or a tag is searched as part of that text, and metafields are not on the Help Center's list of searchable properties.
  4. The dropdown and the results page disagree. They are separate search types, and a theme or app can replace one of them.
  5. Several codes per variant. A variant has one SKU and one barcode field; other codes for the same part (an older number, a supplier number) have no field of their own.

Fixes to try first (no app needed)

  1. Test the results page directly. Open /search?q= followed by the first few characters of a real SKU on your store. If this finds the product but the search dropdown doesn't, the problem is in predictive search or the theme, and your theme developer is the right person to ask.
  2. Search one field. The Help Center describes adding a field name and a colon to narrow a search to that field, for example /search?q=variants.sku:ABC-123. Field names are lowercase and the term follows the colon with no space. This separates "the code is missing" from "other products outrank it".
  3. Put each code in the variant's SKU or Barcode field. Those two fields are on the Help Center's list of searchable product properties.
  4. Write codes so the part shoppers type comes first, or as its own segment. Matching starts at the first character, and a middle piece matches when hyphens, slashes or spaces separate it.
  5. Tell shoppers how to search. A short line near the search box, such as "Type the full part number or its first characters", fits how the built-in search works.
  6. Test on an unedited copy of your theme. If search behaves differently there, a theme edit or another app is changing it.
